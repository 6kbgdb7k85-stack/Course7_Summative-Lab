# Summative Lab: Python Project Management CLI Tool 

Course 7 summative lab

## Setup
- clone repository
- run pipenv install

## Usage
- run pipenv shell
- run python3 main.py [command] [args]
- - example : python3 main.py table users 
- - prints rows from table "users
- - more details can be found in python3 main.py -h

## Features
- view table data
- view entry data
- view projects and tasks assigned to users (separate command for each)
- add entries
- remove entries
- add tasks to projects
- add users to projects
- assign users to tasks
- remove tasks from users
- remove users from projects
- complete tasks and projects
